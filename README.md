# 路的身分證

給高中生用的查詢工具：輸入彰化縣和美鎮的路名或道路編號，回答這條路

1. 在《公路法》上是什麼道路、由誰管、適用哪些條文；
2. 在和美都市計畫裡的編號、計畫寬度、長度與定位；
3. 依《市區道路條例》、《市區道路及附屬工程設計標準》與設計規範，有哪些要求。

115-1 社會探究課「路是給誰走的？」刊物第一章〈路的身分證〉使用。
工具只回答「依規定應該是什麼」，現況要學生自己去量。

另有 `why.html`「一條路，好幾個老闆」：說明道路為什麼由多部法規、多個機關管理，會造成哪些現象，以及五種可能的解法與代價，供課堂討論。

## 本機預覽

```sh

# 開 http://localhost:8765/
```

純靜態網站，沒有建置步驟，也沒有外部相依。

## 資料怎麼來、怎麼更新

```text
data/research/*.json   三份研究原始資料（人工查證後的結果）
        |
        v
scripts/build_data.py  合併，含人工路段對照表 ALIGN
        |
        v
data/roads.json, data/rules.json   網站實際讀的檔案
```

- 改道路或條文：改 `data/research/` 裡對應的 JSON，再跑 `python3 scripts/build_data.py`。
- 不要直接改 `data/roads.json`、`data/rules.json`，下次合併會被蓋掉。
- 同一條路「公路身分的分段」和「都市計畫編號的分段」對不起來時，在 `scripts/build_data.py` 的 `ALIGN` 人工指定；對不準的用 `'all'`，網站會列出各段讓學生自己對位置。
- 研究過程、來源網址與存疑之處寫在 `data/research/*.md`。
- 計畫書 PDF（22 MB）不進版控，網址見 `data/research/hemei-plan.md`。

## 計畫書用語與設計標準用語的對應

和美計畫書用「聯外／主要／次要及出入道路」，設計標準用「主要／次要／服務道路」，
兩套沒有官方對照表。對應寫在 `assets/core.js` 的 `ROLE_MAP`，是推論，可以調整。
對應到多個候選時，網站會把相關條文標成「視道路分類而定」。

## 已知限制

- 只收錄和美主要計畫的計畫道路與境內公路；巷弄、細部計畫道路、交流道特定區的道路未收錄。
- 「不是公路」是把交通部公告路線套疊路名後的反面推論，公路局聲明縣、鄉道圖資僅供參考。
- 設計標準是設計時的要求，第 28 條對既有道路有例外，不能直接推論既有道路違法。
- 管理機關依公路法第 3、6 條填寫；縣府是否委託代養、鎮公所負責哪些日常維護，尚未查證。
